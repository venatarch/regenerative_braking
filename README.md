# Regenerative Braking Energy Recovery Circuit

## Objective

Recover braking energy from a BLDC motor using bidirectional MOSFET switching.

## Hardware

- STM32
- MOSFET Driver
- Current Sensor
- Voltage Sensor

## Software

- KiCad
- MATLAB
- STM32CubeIDE
